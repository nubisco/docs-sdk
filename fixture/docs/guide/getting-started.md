## Install

```sh
pnpm add -D @nubisco/docs-sdk @nubisco/ui vue
```

## Configure

Call `defineNubiscoDocs` from `docs/.vitepress/config.ts` with the product's name,
address, repository, navigation and footer. Everything else is the standard.

## Run

```sh
pnpm exec nubisco-docs dev
```
